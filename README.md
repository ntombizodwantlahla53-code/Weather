# WEATHER-APP

# Project Description
```
This is a responsive Weather Application built using React and TypeScript. The application uses the Visual Crossing Weather API to display weather information based on the user's current location or a searched city. Users can view current, hourly and weekly weather forecasts including temperature, weather conditions, wind, humidity and weather icons. The application also allows users to switch between Celsius and Fahrenheit, change between light and dark mode, manage notification preferences and save searched locations using Local Storage.
```
